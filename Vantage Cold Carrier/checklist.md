# Design Publication Checklist

## Design Files
- [ ] All native CAD files (.SLDPRT, .SLDASM) are included.
- [ ] All assemblies open without errors.
- [ ] All parts are fully constrained and defined.
- [ ] All custom properties (e.g., material, part number) are filled out.

## Manufacturing Files
- [ ] 2D drawings (.SLDDRW) are created for all manufactured parts.
- [ ] Drawings are exported to PDF format.
- [ ] STEP files are created for all assemblies and manufactured parts.
- [ ] DXF/DWG files are created for any sheet metal or laser/waterjet cut parts.

## Documentation
- [ ] Bill of Materials (BOM) is complete and accurate.
- [ ] Assembly instructions are created.
- [ ] A README file with a description of the design is present.
- [ ] Renderings or images of the final design are included.

## Review
- [ ] Design has been reviewed for manufacturability.
- [ ] Drawings have been checked for clarity and accuracy.
- [ ] BOM has been verified against the assembly.
